# 아르피아 리메이크 — 결정 로그

## 사용자 확정

1. 전투: **C — 반실시간 액션 + 스킬 쿨다운**
2. 첫 지역: **고요한 안개숲 + 오염 몬스터 혼합안**
3. 첫 원소: **프롤로그 선택 누적 + 위기에서 자동 각성**
4. 정령 성격: **C — 작고 신비롭지만 은근히 엉뚱한 안내자**
5. 나머지는 추천안으로 진행

## 자동 확정한 추천안

- 정령 이름: **모아**
- 비주얼: **2D 일러스트풍 SD 캐릭터**
- 전투 구성: **주인공 1명 조작 + 동료 자동 보조**
- 분위기: **밝은 판타지 70% + 감정 드라마 30%**
- 첫 마을: **루메르 변두리**
- 첫 퀘스트: **안개숲의 잔향**
- 첫 보스: **뒤엉킨 잔향**
- 첫 챕터 결론: 감정을 제거하지 않고 방향을 되찾는다.
