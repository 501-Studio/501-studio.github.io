# 아르피아 리메이크 — 인터뷰 결정 로그

## 인터뷰 1. 전투 방식 — LOCKED

**결정:** C — 반실시간 액션 + 스킬 쿨다운

### 설계 해석
- 필드 이동은 실시간.
- 기본 공격은 즉시 입력.
- 핵심 원소 스킬은 쿨다운 + 감정 게이지 기반.
- 대시/회피로 위치 선정.
- 복잡한 콤보보다는 짧고 읽기 쉬운 전투 루프를 우선.
- 웹/모바일 확장을 고려해 액티브 입력 수를 과도하게 늘리지 않음.

### 현재 MVP와의 연결
현재 프로토타입 전투 구조와 방향이 일치하므로 전투 장르 자체는 교체하지 않고, 이후 인터뷰를 통해 적 패턴·스킬 슬롯·원소 숙련·전투 템포를 세부 조정한다.

## 인터뷰 2. 이세계 첫 지역과 초반 분위기

### 후보 1 — 밝은 변두리 초원 + 작은 마을
현실의 답답함과 정반대인 넓고 밝은 풍경에서 시작. 탐색과 NPC 대화를 먼저 경험한 뒤 첫 전투로 연결한다.

### 후보 2 — 무너진 숲길 + 감정에 오염된 몬스터
눈을 뜨자마자 이상 현상을 발견하고 짧은 전투 튜토리얼부터 시작. 이후 마을로 이동한다. 초반 몰입과 게임성을 가장 빠르게 보여줄 수 있다.

### 후보 3 — 고요한 안개숲 + 정령
전투보다 신비감과 감정/원소 세계관을 먼저 보여준다. 정령과의 만남을 통해 첫 원소 마법을 배우고 숲을 빠져나가는 흐름.

**다음 결정:** 후보 1 / 2 / 3 중 하나 또는 혼합안.
