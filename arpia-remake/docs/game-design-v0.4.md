# 아르피아 리메이크 게임 디자인 v0.4

## 1. 제품 목표

20~35분 안에 현실 프롤로그, 첫 원소 각성, 마을, 메인/서브 퀘스트, 상점, 펫 성장, 스킬 투자, 첫 보스를 모두 경험하는 웹 RPG 버티컬 슬라이스를 만든다.

## 2. 핵심 경험

`현실의 감정 선택 → 첫 원소 자동 판정 → 감정을 전투 기술로 사용 → 퀘스트에서 감정의 의미를 다시 해석 → 새로운 감정과 원소를 이해`

첫 원소는 직업 선택이 아니라 주인공이 현재 가장 익숙하게 다루는 감정이다. 다른 원소는 후속 지역의 서사와 퀘스트를 통해 해금한다.

## 3. 화면 구조

### 타이틀

- 전경 캐릭터와 모아, 원경 판타지 마을과 산맥
- 중앙 세로 메뉴
- 좌측 저장 데이터/현재 퀘스트 미리보기
- 반투명 남색 패널, 얇은 금색·청색 테두리

### 프롤로그

- 상단 챕터명과 SKIP
- 좌측 주인공, 우측 감정 선택 카드
- 하단 화자명과 대화창
- 선택 색상은 발현될 원소 색상과 연결

### 필드/전투

- 하단 캐릭터 상태와 스킬 슬롯
- 우측 메인·서브 퀘스트 추적기
- 우상단 원형 미니맵
- 하단 시스템 로그
- 보스전은 화면 상단에 이름과 HP를 배치

### 통합 메뉴

- 하단 고정 탭: 상태/가방/스킬/퀘스트/일지/도감/펫/상점/설정
- 모든 기능을 별도 HTML 화면이 아니라 Phaser Scene 위 오버레이로 유지
- 메뉴 진입 시 월드 물리를 일시정지하고 닫을 때 복원

## 4. 퀘스트 구조

### 메인 퀘스트: 제1장 · 감정의 잔향

1. 현실의 마지막 금요일
2. 안개숲에서 깨어남
3. 모아와 첫 대화
4. 첫 원소 각성
5. 루메르 변두리 마을 도착
6. 공명 조각 3개 회수
7. 보스 뒤엉킨 잔향 정화
8. 마을 귀환과 보고

### 서브 퀘스트

- 모아의 부탁: 별빛 꽃잎 3개 수집 → 펫 경험치와 간식
- 수상한 흔적: 오염 흔적 5개 조사 → 골드와 스킬 포인트

## 5. 상점

- 회복 물약
- 감정 회복약
- 별빛 간식
- 공명 강화석
- 스킬 초기화권

구매는 골드 또는 결정 재화를 소모하며 즉시 세이브에 반영한다.

## 6. 펫: 모아

- 기본 소환 상태
- 가장 가까운 적에게 자동 탄환
- 플레이어 HP가 위험 구간에 도달하면 자동 회복
- 레벨은 공격/회복 수치에, 유대는 발동 주기에 반영
- 별빛 간식으로 유대와 경험치 증가

## 7. 스킬트리

각 원소는 네 가지 노드를 가진다.

- 기본: 기본 공격 강화
- 흐름: 쿨다운 및 감정 소모 개선
- 숙련: 원소 스킬 위력 증가
- 공명: 원소 정체성을 강화하는 상위 효과

스킬 포인트는 퀘스트, 보스, 레벨업으로 획득한다.

## 8. 모션 원칙

- 이동 입력은 즉시 속도 전환하지 않고 지수 보간
- 캐릭터는 이동 속도에 비례한 미세한 스쿼시/바운스
- 모아는 목표점을 부드럽게 추적하고 사인 곡선으로 부유
- 대시는 잔상과 짧은 무적을 함께 제공
- 공격은 짧은 전진 트윈, 슬래시 확대/페이드
- UI 패널은 120~220 ms 범위의 짧은 피드백만 사용

## 9. 저장 구조

- 체크포인트
- 플레이어 레벨/경험치/재화/인벤토리
- 감정 선택과 원소 성향
- 메인·서브 퀘스트 상태
- 펫 레벨/경험치/유대/소환 상태
- 원소별 스킬 투자
- 일지와 설정

v0.3 세이브는 v0.4 기본 구조와 병합해 마이그레이션한다.
