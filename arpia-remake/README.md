# 아르피아 리메이크 — MVP v0.3

웹 기반 캐주얼 액션 RPG 프로토타입. Vite + Phaser 기반이며, 원작의 작은 캐릭터/필드 전투/HUD 감각을 참고하되 핵심은 **감정 → 원소 → 마법 숙련** 구조에 둔다.

## 확정된 핵심 방향

- 전투: 반실시간 액션 + 스킬 쿨다운
- 첫 지역: 고요한 안개숲 → 정령 조우 → 오염 몬스터 → 첫 전투
- 첫 원소: 현실 프롤로그의 감정 선택 누적 결과로 자동 각성
- 첫 원소는 직업이 아니라 현재 가장 익숙하게 이해하는 감정
- 다른 원소는 스토리와 감정 이해 퀘스트를 통해 해금
- 안내 정령: **모아(Moa)** — 신비로운 첫인상 + 인간 상식에 약한 엉뚱한 동료
- 첫 거점: **루메르 변두리 마을**
- 첫 퀘스트: **안개숲의 잔향**
- 첫 보스: **뒤엉킨 잔향**

## 현재 플레이 흐름

1. 현실 회사 프롤로그
2. 4개의 감정 선택 장면
3. 옥상에서 세계 전환
4. 안개숲에서 모아 조우
5. 누적 감정에 따른 첫 원소 판정
6. 오염 몬스터 출현
7. 반실시간 액션 전투 튜토리얼
8. 감정의 잔재 7체 정화
9. 모아를 따라 숲 밖으로 이동
10. 루메르 변두리 마을 발견
11. 첫 퀘스트와 첫 보스 예고

## 조작

- `WASD`: 이동
- `Space` 또는 `J`: 기본 공격
- `Q`: 원소 스킬
- `Shift`: 대시
- 프롤로그/대화: `Space`, 클릭, 선택지 `1~3`
- 첫 전투 승리: `Enter`로 루메르 진입 장면
- 데모 마지막: `R`로 처음부터

## 원소

| 원소 | 감정 축 | 첫 Q 스킬 |
| --- | --- | --- |
| 불 | 열정·용기 ↔ 분노·조급함 | 타오르는 마음 |
| 물 | 평온·공감 ↔ 슬픔·무기력 | 흘려보내기 |
| 어둠 | 성찰·안식 ↔ 공포·고독 | 내면 잠행 |
| 번개 | 영감·각성 ↔ 불안·충동 | 찰나의 깨달음 |
| 바람 | 해방·호기심 ↔ 허무·냉담 | 경계 너머 |
| 빛 | 희망·명료함 ↔ 오만·완벽주의 | 길을 밝히는 빛 |

## 자동 개발 원칙

이후 일반적인 기획 결정은 추천안을 기본값으로 자동 확정한다. 사용자에게는 게임의 정체성이나 기술 구조를 크게 바꾸는 결정만 질문한다.

### 현재 남은 핵심 질문 3개

1. 비주얼: 픽셀 / 2D 일러스트풍 SD(추천) / 원작 레트로 웹게임풍
2. 전투 인원: 주인공 단독 중심(추천) / 3인 파티 / 동료는 스토리 NPC만
3. 전체 톤: 밝은 모험 70 + 감정 드라마 30(추천) / 50:50 / 진한 감정 드라마 중심
