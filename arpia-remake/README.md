# 아르피아 리메이크 — MVP v0.1

웹 기반 캐주얼 액션 RPG 프로토타입. Vite + Phaser로 구성되어 있으며, 원작의 작은 캐릭터/필드 전투/HUD 감각을 참고하되 리메이크의 핵심은 **감정 → 원소 → 마법 숙련** 구조에 둔다.

## 현재 구현

- 챕터 1 프롤로그: 평범한 출근 → 최악의 금요일 → 옥상 → 이세계 전환
- 첫 원소 각성: 불 / 물 / 어둠 / 번개 / 바람 / 빛 중 선택
- 기본 전투 루프: 이동 → 기본 공격 → 감정 게이지 축적 → 원소 스킬 → 적 7체 정화
- 원소별 Q 스킬 6종
- HP / 보호막 / 감정 게이지 / 스킬 쿨다운 / 퀘스트 HUD
- 게임 오버 / 재시작 / 원소 재선택
- 16:9 반응형 Phaser 캔버스

## 실행

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

## 조작

- `WASD`: 이동
- `Space` 또는 `J`: 기본 공격
- `Q`: 원소 스킬
- `Shift`: 대시
- 프롤로그: `Space` 또는 클릭
- 전투 종료: `Enter` 재전투 / `Esc` 원소 재선택

## 원소 스킬

| 원소 | 감정 축 | MVP 스킬 |
| --- | --- | --- |
| 불 | 열정·용기 ↔ 분노·조급함 | 근거리 폭발 |
| 물 | 평온·공감 ↔ 슬픔·무기력 | 회복 + 밀쳐내기 |
| 어둠 | 성찰·안식 ↔ 공포·절망 | 순간이동 + 짧은 무적 |
| 번개 | 영감·각성 ↔ 불안·충동 | 3체 연쇄 타격 |
| 바람 | 해방·호기심 ↔ 허무·냉담 | 8방향 투사체 |
| 빛 | 희망·명료함 ↔ 오만·강박 | 전체 타격 + 보호막 |

## MVP 이후 개발 순서

1. 인터뷰로 전투 코어 확정: 실시간 / 턴제 / 반실시간
2. 주인공 캐릭터 및 몬스터 최종 아트 방향 확정
3. 챕터 1 이세계 도착 후 NPC 1명 + 첫 퀘스트 추가
4. 감정 선택지가 전투 수치와 대사에 미치는 영향 추가
5. 원소 숙련도/스킬 트리 최소 버전 추가
6. 저장/불러오기(localStorage)
7. 보스 1종 추가 후 20~30분 분량 데모 완성
8. 모바일 입력 및 사운드 추가
9. GitHub Pages 배포 자동화

## 개발 원칙

- 혼자 개발 가능한 범위를 유지한다.
- 시스템을 먼저 검증하고 콘텐츠를 늘린다.
- 아트가 확정되기 전까지 프로토타입 그래픽은 교체 가능한 구조로 유지한다.
- 감정 시스템은 단순 속성 상성이 아니라 스토리 선택·원소 숙련·전투 스킬을 연결하는 중심 시스템으로 사용한다.
