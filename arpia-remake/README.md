# 아르피아 리메이크 — v0.4.0

Vite + Phaser 기반 웹 캐주얼 액션 RPG 버티컬 슬라이스입니다. 핵심 구조는 **감정 → 원소 → 마법 숙련**이며, 어두운 청색 패널·금색 테두리·하단 스킬바·우측 퀘스트 추적기를 사용하는 판타지 RPG UI로 개편했습니다.

## 구현된 플레이 흐름

1. 타이틀 화면과 새 게임/이어하기
2. 회사 프롤로그와 감정 선택 4회
3. 선택 누적을 통한 첫 원소 자동 각성
4. 안개숲에서 모아 조우 및 첫 전투
5. 루메르 변두리 마을과 장로/상인 NPC
6. 메인 퀘스트 `안개숲의 잔향`
7. 서브 퀘스트 `모아의 부탁`, `수상한 흔적`
8. 공명 조각 수집과 보스 `뒤엉킨 잔향`
9. 마을 귀환 및 챕터 1 완료

## 시스템

- 반실시간 액션: 이동, 기본 공격, 원소 스킬, 범위 공명, 펫 스킬, 대시
- 9개 메뉴: 상태, 가방, 스킬, 퀘스트, 일지, 도감, 펫, 상점, 설정
- 상점 및 소비 아이템
- 모아 자동 공격, 회복 스킬, 레벨/유대/소환/먹이
- 첫 원소별 스킬트리 3분기
- 메인·서브 퀘스트 진행도와 보상
- `localStorage` 자동 저장 및 이어하기
- 속도 보간, 캐릭터 호흡/보행, 펫 추종, 대시 잔상, 타격 숫자, 카메라 효과
- 키보드와 터치 방향 입력

## 조작

| 키 | 기능 |
|---|---|
| WASD | 이동 |
| Space / J / 1 | 기본 공격 |
| Q / 2 | 원소 핵심 스킬 |
| 3 | 원소 범위 공명 |
| 4 | 모아의 위로 |
| Shift | 대시 |
| E | NPC·포털 상호작용 |
| Tab | 통합 메뉴 |
| B / L | 가방 / 퀘스트 바로 열기 |
