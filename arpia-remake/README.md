# 아르피아 리메이크 — Chapter 1 Vertical Slice

감정이 원소로 번역되는 세계를 배경으로 한 웹 기반 캐주얼 액션 RPG입니다.  
**Vite + Phaser**, 1인 개발, 빠른 MVP 검증을 기준으로 구성했습니다.

## 현재 버전

`v0.3.0` — 프롤로그부터 첫 보스와 챕터 클리어까지 연결된 플레이 가능한 세로 단면 데모.

## 확정된 방향

- 비주얼: 2D 일러스트풍 SD 캐릭터
- 전투: 반실시간 액션 + 스킬 쿨다운
- 캐릭터 구성: 주인공 1명 직접 조작 + 동료는 보조/스토리 역할
- 전체 톤: 밝은 판타지 모험 70% + 감정 드라마 30%
- 첫 지역: 고요한 안개숲 → 모아 조우 → 오염 몬스터 → 첫 원소 각성
- 첫 원소: 직접 선택하지 않고 현실 프롤로그의 감정 선택 결과로 자동 결정
- 성장: 원소 수집보다 각 감정을 이해하는 사건과 퀘스트를 통해 해금

## 플레이 흐름

1. 타이틀 / 새 게임 / 이어하기
2. 회사 프롤로그와 감정 선택 4회
3. 선택 결과를 바탕으로 6원소 중 첫 원소 판정
4. 안개숲 탐색
5. 정령 **모아** 조우
6. 첫 원소 각성 및 전투 튜토리얼
7. 루메르 변두리 마을 진입
8. 첫 퀘스트 **「안개숲의 잔향」** 수락
9. 잔향 조각 3개 수집
10. 첫 보스 **「뒤엉킨 잔향」** 전투
11. Chapter 1 클리어

## 구현 기능

- Phaser Scene 9개로 분리된 게임 흐름
- 불 / 물 / 어둠 / 번개 / 바람 / 빛 감정 점수 누적
- 최고 점수 동률 시 최근 감정을 우선하는 첫 원소 판정
- 원소별 Q 스킬 6종
- 기본 공격, 대시, 회복 물약, HP, 보호막, 감정 게이지, 쿨다운
- 일반 몬스터 웨이브와 보스 패턴
- 탐색, NPC 대화, 퀘스트 수락, 수집 목표
- 키보드 + 터치 조작
- `localStorage` 자동 저장 / 이어하기 / 초기화
- 반응형 16:9 게임 셸
- GitHub Actions 빌드 및 Pages 배포 워크플로

## 조작

| 입력 | 기능 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| `Space` / `J` | 기본 공격, 대화 넘기기 |
| `Q` | 현재 원소 스킬 |
| `E` | 회복 물약 |
| `Shift` | 대시 + 짧은 무적 |
| `F` | 조사 / 대화 / 퀘스트 진행 |
| `Esc` | 타이틀로 이동 |

터치 기기에서는 게임 화면 안에 가상 방향키와 행동 버튼이 표시됩니다.

## 실행

```bash
npm install
npm run dev
```

## 검증 및 빌드

```bash
npm run check
```

`check`는 다음을 수행합니다.

1. JavaScript 문법 검사
2. 필수 Scene 및 핵심 게임 토큰 구조 검사
3. Vite 프로덕션 빌드

## 배포

`main` 브랜치에 병합되면 `.github/workflows/arpia-remake-pages.yml`이 실행됩니다.

- 기존 저장소 루트 페이지는 유지
- 게임은 `/arpia-remake/` 하위 경로로 빌드
- GitHub Pages artifact로 배포

저장소 Settings → Pages → Source가 **GitHub Actions**로 설정되어 있어야 합니다.

## 개발 원칙

- 한 번에 콘텐츠를 늘리지 않고, 완결된 짧은 플레이 루프부터 검증한다.
- 감정 시스템은 단순 속성 상성이 아니라 대사, 퀘스트, 성장, 전투를 잇는 중심 시스템으로 사용한다.
- 조작 버튼 수와 데이터 구조는 모바일 웹 확장을 고려해 제한한다.
- 원작의 작은 캐릭터, 필드 전투, 하단 HUD 감각은 유지하되 UI와 진행 구조는 현대화한다.
