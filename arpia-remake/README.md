# 아르피아 리메이크 — Vertical Slice v0.4.0

감정이 원소 마법으로 번역되는 **웹 기반 2D 캐주얼 액션 RPG**입니다. 1인 개발과 빠른 MVP 검증을 기준으로 Vite + Phaser 3 구조를 사용합니다.

이번 버전은 제공된 RPG 화면 시안을 기준으로 타이틀, 프롤로그 선택지, 필드 HUD, 퀘스트 추적기, 통합 메뉴를 하나의 어두운 판타지 UI 시스템으로 재구성했습니다.

## v0.4 핵심 업데이트

### 화면과 조작감

- 시안 기반 타이틀 화면: 로고, 새 게임/이어하기/설정/제작자/종료, 저장 데이터 미리보기
- 시안 기반 프롤로그: 상단 챕터 표시, SKIP, 우측 감정 선택 패널, 하단 대화창, 진행도
- 시안 기반 전투 HUD: 캐릭터 상태, HP/감정/EXP, 스킬 슬롯, 시스템 로그, 미니맵, 메인·서브 퀘스트 추적기
- 가속·감속이 적용된 이동, 보간 추적, 보행 바운스, 대시 잔상, 적 이동 보간
- 키보드와 모바일 터치 조작

### 콘텐츠와 성장

- 메인 퀘스트 **「제1장 · 감정의 잔향」** 8단계
- 서브 퀘스트 **「모아의 부탁」**, **「수상한 흔적」**
- 루메르 마을 상점과 실제 구매·소모 기능
- 정령 펫 **모아**: 소환/해제, 자동 공격, 위기 회복, 레벨·유대·간식 성장
- 6원소 스킬트리: 기본 강화, 흐름, 숙련, 공명
- 회복 물약·감정 회복약 단축키
- 전투와 퀘스트 보상으로 골드, 경험치, 스킬 포인트, 펫 경험치 획득
- `localStorage` v0.4 저장 및 v0.3 세이브 마이그레이션

## 확정된 기획 방향

- 전투: **반실시간 액션 + 스킬 쿨다운**
- 비주얼: **2D 일러스트풍 SD 캐릭터**
- 캐릭터 구성: **주인공 1명 직접 조작 + 모아 자동 보조**
- 전체 톤: **밝은 판타지 모험 70% + 감정 드라마 30%**
- 첫 지역: **고요한 안개숲 → 정령 조우 → 오염 몬스터 → 첫 전투**
- 첫 원소: 직접 선택이 아니라 현실 프롤로그의 감정 선택으로 자동 결정
- 성장 핵심: 원소 수집보다 **감정 이해의 확장**

## 조작

| 입력 | 기능 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| `Space` / `J` | 기본 공격 |
| `Q` | 원소 마법 |
| `E` | 조사·대화·이동 |
| `Shift` | 대시 및 짧은 무적 |
| `1` / `2` | 회복 물약 / 감정 회복약 |
| `Tab` | 통합 메뉴 |
| `B` / `K` / `L` / `P` | 가방 / 스킬 / 퀘스트 / 펫 메뉴 |
| `Esc` | 메뉴 닫기 또는 일시정지 |
| 모바일 | 화면 내 방향·공격·마법·조사·대시 버튼 |

## 통합 메뉴

- **상태**: 레벨, 경험치, 원소 성향, 현재 목표, 재화
- **가방**: 소모품 확인과 즉시 사용
- **스킬**: 원소별 스킬 노드 투자와 초기화
- **퀘스트**: 메인·서브 퀘스트 진행도와 보상 수령
- **일지**: 주요 사건과 감정 선택 기록
- **도감**: 원소와 감정 체계 확인
- **펫**: 모아 소환, 성장, 간식 사용
- **상점**: 물약·재료·초기화권 구매
- **설정**: 사운드, 화면 흔들림, 미니맵, 전체 화면

## 원소 마법

| 원소 | 감정 축 | Q 스킬 |
| --- | --- | --- |
| 불 | 열정·용기 ↔ 분노·조급함 | 주변 폭발 |
| 물 | 평온·공감 ↔ 슬픔·무기력 | 회복 + 밀쳐내기 |
| 어둠 | 성찰·안식 ↔ 공포·고독 | 순간이동 + 무적 |
| 번개 | 영감·각성 ↔ 불안·충동 | 연쇄 타격 |
| 바람 | 해방·호기심 ↔ 허무·냉담 | 8방향 바람 칼날 |
| 빛 | 희망·명료함 ↔ 오만·완벽주의 | 전체 타격 + 보호막 |

## 실행

```bash
cd arpia-remake
npm install
npm run dev
```

검사 및 빌드:

```bash
npm run check
npm run build
npm run preview
```

Vite의 배포 base는 GitHub Pages의 `/arpia-remake/` 경로로 설정되어 있습니다.

## 코드 구조

```text
src/
├── data/          # 원소, 스토리, 퀘스트, 상점, 펫, 스킬트리 데이터
├── game/          # 저장, 진행도, 입력, 메뉴, UI, 오디오, 공통 액션 시스템
├── scenes/        # 타이틀부터 엔딩까지 Phaser Scene
├── main.js        # Phaser 설정과 Scene 등록
└── style.css      # 게임 외부 셸과 반응형 화면
public/assets/     # 교체 가능한 SVG 배경·캐릭터·몬스터·UI 자산
```

## 검증

```bash
npm run check
```

은 `src/`와 `scripts/`의 JavaScript 파일을 순회해 Node 구문 검사를 실행합니다. GitHub Actions는 Node 22에서 설치, 구문 검사, Vite production build를 수행하고 `dist/`를 아티팩트로 보존합니다.
