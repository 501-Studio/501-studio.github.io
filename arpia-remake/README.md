# 아르피아 리메이크 — MVP v0.2

웹 기반 캐주얼 액션 RPG 프로토타입. Vite + Phaser 기반이며, 원작의 작은 캐릭터/필드 전투/HUD 감각을 참고하되 핵심은 **감정 → 원소 → 마법 숙련** 구조에 둔다.

## 확정된 핵심 방향

- 전투: 반실시간 액션 + 스킬 쿨다운
- 첫 지역: 고요한 안개숲 → 정령 조우 → 오염 몬스터 → 첫 전투
- 첫 원소: 플레이어가 직접 고르지 않음
- 현실 프롤로그의 감정 선택을 누적해 첫 원소가 자동 각성
- 첫 원소는 직업이 아니라 현재 가장 잘 이해하는 감정
- 다른 원소는 스토리와 감정 이해 퀘스트를 통해 해금

## 현재 플레이 흐름

1. 현실 회사 프롤로그
2. 4개의 감정 선택 장면
3. 옥상에서 세계 전환
4. 안개숲에서 작은 정령 조우
5. 누적 감정에 따른 첫 원소 판정
6. 오염 몬스터 출현
7. 반실시간 액션 전투 튜토리얼
8. 감정의 잔재 7체 정화

## 조작

- `WASD`: 이동
- `Space` 또는 `J`: 기본 공격
- `Q`: 원소 스킬
- `Shift`: 대시
- 프롤로그: `Space`, 클릭, 선택지 `1~3`
- 전투 종료: `Enter` 재전투 / `Esc` 프롤로그부터 다시

## 원소

| 원소 | 감정 축 | 첫 Q 스킬 |
| --- | --- | --- |
| 불 | 열정·용기 ↔ 분노·조급함 | 타오르는 마음 |
| 물 | 평온·공감 ↔ 슬픔·무기력 | 흘려보내기 |
| 어둠 | 성찰·안식 ↔ 공포·고독 | 내면 잠행 |
| 번개 | 영감·각성 ↔ 불안·충동 | 찰나의 깨달음 |
| 바람 | 해방·호기심 ↔ 허무·냉담 | 경계 너머 |
| 빛 | 희망·명료함 ↔ 오만·완벽주의 | 길을 밝히는 빛 |

## 실행
