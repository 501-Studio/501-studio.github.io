# 아르피아 리메이크 — v0.4.0

Vite + Phaser 기반 웹 캐주얼 액션 RPG 버티컬 슬라이스입니다.

## 이번 코드 업데이트

- 제공된 RPG 시안을 기준으로 타이틀·프롤로그·전투 HUD·미니맵·퀘스트 추적기·통합 메뉴를 어두운 판타지 UI로 재구성
- 현실 프롤로그 감정 선택 4회와 첫 원소 자동 각성
- 반실시간 액션 전투: 이동, 기본 공격, 원소 마법, 감정 폭발, 대시, 물약
- 메인 퀘스트 8단계와 서브 퀘스트 2종
- 루메르 상점과 실제 재화·구매·인벤토리 처리
- 정령 펫 모아: 소환, 자동 공격, 위기 회복, 경험치, 유대감, 간식 성장
- 6원소 스킬트리와 스킬 포인트 투자·초기화
- 가속·감속 이동, 보행 바운스, 모아 보간 추적, 대시 잔상, 공격 트윈
- localStorage v0.4 저장
- 키보드와 모바일 터치 입력

## 실행

```bash
npm install
npm run dev
```

검사와 빌드:

```bash
npm run check
npm run build
```

GitHub Actions에서 Node 22 의존성 설치, 정적 검사, Vite production build, 빌드 아티팩트 업로드까지 통과했습니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| Space / J | 기본 공격 |
| Q | 원소 마법 |
| E | 조사·대화·이동 |
| Shift | 대시 |
| 1 / 2 | HP / 감정 물약 |
| Tab | 통합 메뉴 |
| Esc | 메뉴 닫기·일시정지 |

1. 타이틀 화면
