Local-first

SimsimLAB calculates quiz answers in your browser. Solo answers are not sent to a SimsimLAB backend because there is no application backend.

2 Player links

Two-player answer data is packed into the URL fragment after #. Browsers do not send URL fragments in normal HTTP requests. Optional nicknames are only included in the fragment when you choose to add one.

Browser storage

Favorites and recently tried tests use localStorage. You can clear them with your browser’s site-data controls at any time.

Hosting logs

GitHub Pages or a future CDN may process normal connection information such as IP address and user agent as part of serving the site. SimsimLAB does not add an analytics provider in this release.
