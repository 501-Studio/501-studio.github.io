# 톡텐션 운영 안내

서비스: https://toktension-501.onrender.com/

소스: `apps/tok-tension` 브랜치의 `tok-tension/` 폴더.

기존 저장소의 `main` 및 다른 앱은 변경하지 않았습니다. Render에는 이 앱만을 위한 독립 정적 사이트를 생성했습니다.

## 현재 구현된 기능

- 카톡 내보내기 텍스트 및 `이름: 내용` 형식 분석, UTF-8/CP949/EUC-KR/UTF-16 BOM 텍스트 파일 가져오기.
- 참여자 선택, 단체방에서 선택한 두 사람 비교.
- 메시지 개수와 공백 제외 글자 수, 질문 메시지 비율, 제한된 웃음·긍정 표현 집계.
- 표면적 통계로 만드는 결정적 놀이 지수와 대화 유형 6종.
- 시간 정보가 있을 때만 인접 발신자 전환 구간의 답장 간격 중앙값 계산. 6시간 초과·역순 시간·제삼자가 끼어든 구간 제외.
- 마지막 상대방 메시지의 키워드를 이용한 문장 템플릿 추천: 가볍게/다정하게/약속 잡기.
- 익명 1080 x 1350 PNG 저장, 지원 기기의 Web Share API, 익명 결과 링크, X 작성 화면 열기.
- 추가 분석 5종 무료 공개, 개인정보 및 이용 안내, 입력 삭제.

## 미연결 사항 — 수익화가 완료된 상태가 아닙니다

현재 실제 광고 요청, 광고 계정, 승인된 광고 단위, 광고 수익 정산은 연결하지 않았습니다. 광고를 본 것처럼 꾸미는 타이머도 없습니다. 모든 추가 분석은 무료입니다. 외부 AI API와 카카오 전용 JavaScript SDK도 연결하지 않았습니다.

보상형 광고를 도입하려면 실제 운영자가 사용 가능한 광고 계정과 광고 단위를 준비해야 합니다. 배너 광고와 보상형 광고는 별도 형식이며, 임의 배너 클릭을 유도해 보상형 광고를 흉내 내면 안 됩니다. 사용자에게 받을 보상을 명확히 설명하고 자발적인 동의를 받은 후 광고를 표시해야 합니다. 단순한 동영상 종료나 창 닫힘이 아니라 광고 제공업체의 보상 지급 확인 이벤트를 기준으로 추가 기능을 열어야 합니다. 광고가 없거나 지원되지 않는 환경을 별도로 처리해야 합니다.

Google Publisher Tag 공식 보상형 예제:
https://developers.google.com/publisher-tag/samples/display-rewarded-ad

권장 후속 구현: 광고 SDK를 원문 입력 DOM과 분리된 별도 출처 광고 페이지에서 실행합니다. 열려 있는 원문 페이지에 광고 SDK를 직접 삽입하면 그 스크립트는 원문에 접근할 수 있어 현재의 개인정보 보장이 약해집니다. 원문을 광고 페이지·URL·분석 이벤트로 전달하지 말고, 정확한 origin/source/nonce를 검사하는 제한된 완료 메시지만 사용합니다. 이 구조는 아직 구현되지 않았습니다.

광고 활성화 시 현재 CSP, 개인정보 안내, 동의 방식, 광고 공급업체 정책, 실제 기기에서의 광고 적격성 등을 함께 재검토해야 합니다. 클라이언트 측 무료 기능 해제는 사용자가 우회할 수 있으며 결제 보안 장치가 아닙니다.

## 개인정보 및 해석 제한

`engine.js`와 `app.js`는 입력을 서버로 전송하지 않습니다. 외부 API, 추적 SDK, 쿠키, localStorage, sessionStorage, IndexedDB를 사용하지 않습니다. CSP의 connect-src는 none입니다. 사이트 접속 자체의 IP/접속 기록은 호스팅 업체가 처리할 수 있습니다.

결과 링크는 URL fragment에 점수와 유형만 저장합니다. 원문, 실제 이름, 마지막 메시지는 포함하지 않습니다. 링크 수치는 사용자가 수정할 수 있고 서버 검증/서명이 없습니다. 링크 받는 화면에 이 점을 고지합니다.

점수는 과학적으로 검증된 심리 측정값이나 실제 호감도가 아닙니다. 시간 간격은 읽음 시각이 아닌 발신 메시지 사이의 차이입니다. 물음표 없는 질문, 비꼬는 웃음, 상황과 관계 맥락은 이해하지 못합니다. 대화 참여자의 동의를 받고 실명·연락처·민감한 내용은 입력 전에 제거하도록 안내합니다.

## 파일 구성 및 로컬 실행

- `index.html`: 반응형 화면, 스타일, FAQ, 접근성 요소.
- `engine.js`: 대화 파서, 통계, 놀이 지수, 문장 템플릿, 공유 데이터 검증.
- `app.js`: UI 상태, 파일 읽기, 캔버스 이미지 생성, 공유, 삭제.

추가 빌드 없이 정적 파일로 실행합니다.

```sh
cd tok-tension
python -m http.server 8080
```

브라우저에서 localhost:8080을 엽니다. 외부 공유는 브라우저의 HTTPS·사용자 동작·운영체제 지원 조건에 따라 달라집니다.

빌드 명령:

```sh
node --check tok-tension/engine.js && node --check tok-tension/app.js && test -s tok-tension/index.html
```

앱 자체에는 유료 AI API나 별도 서버/데이터베이스가 없습니다. 호스팅 사용량·트래픽·향후 광고/외부 서비스 비용까지 무제한 무료임을 의미하지는 않습니다.

## 테스트

- `.github/workflows/tok-tension-check.yml`: Node 문법 및 20개 파서/계산/입력 검증 회귀 검사.

- 브라우저 검사에서 운영체제 공유 창과 클립보드는 테스트 대역으로 교체하여 전달되는 데이터만 검사합니다. 실제 카카오톡·인스타그램 앱 전환이나 Safari 동작을 검증했다는 뜻이 아닙니다.
