# 코토바 0.4.1 내부 개발본

0.4.0 자동 발음 반영본에서 이어지는 기능 안내 업데이트입니다. 공개 웹사이트/Google Play 배포와 결제 승인 상태는 변경하지 않습니다.

## 사용법

처음 홈에 들어오면 짧은 5단계 안내를 표시합니다. 아는/모르는 단어 분류, 자동 발음과 글자 쓰기, 중단·복습, 단어장, 내 기록·설정을 소개합니다. 실제 단어를 학습하거나 보상을 지급하는 체험 수업은 아닙니다.

이전/다음/건너뛰기를 제공하고 마지막에는 시작하기가 있습니다. 완료하거나 건너뛴 안내는 다시 자동 표시하지 않습니다. 안내 도중 앱이 종료되면 저장한 단계에서 이어집니다. 설정 → 튜토리얼 다시 보기는 언제나 첫 단계에서 시작하고 닫으면 설정으로 돌아옵니다.

기존 앱을 업데이트해 저장된 수업이 자동 복원되는 경우에는 수업을 가리지 않습니다. 이후 홈으로 돌아왔을 때 안내합니다. 브라우저 Escape와 Android 뒤로 가기도 건너뛰기/닫기로 처리합니다.

## 기록 보호

안내 상태는 기존 IndexedDB의 `state` 저장소 내 별도 `tutorial-v1` 키에 저장합니다. 실제 학습 `current` 기록, XP, SRS, 필기, 보관 수업, 단어장과 독립적입니다. 학습 백업 가져오기/초기화는 기기별 안내 상태를 덮어쓰지 않습니다. 재설치·새 기기에서는 첫 실행 안내가 다시 나올 수 있습니다.

다른 탭의 지연된 진행 저장이 이미 완료/건너뛴 상태를 되돌리지 않도록 트랜잭션에서 병합합니다. 안내 상태만 저장하지 못하는 경우 그 사실을 표시하되 학습 기능은 차단하지 않습니다.

## 접근성 및 오디오

안내 제목으로 초기 포커스를 이동하고 Tab/Shift+Tab을 안내 안에 유지합니다. 배경 화면은 inert로 처리합니다. 작은 화면, 가로 모드, 확대된 글자에서는 본문만 스크롤하고 다음/닫기 버튼은 유지합니다. 모션 감소 설정을 존중하고 자동 넘김이나 강제 음성 재생을 넣지 않았습니다.

안내/설정 등 대화상자 뒤에서 지연된 단어 자동 발음이 시작되지 않도록 검사합니다. 예문 창을 닫은 뒤 예약된 발음이 재생되던 경합도 방지합니다. 빠른 확인(아는 단어/모르는 단어 분류)은 자동 발음을 하지 않고 카드의 `발음 듣기` 버튼으로만 재생합니다. 쓰기·객관식·정답/예문 등 나머지 학습 단계의 최초 1회 자동 발음과 기기 일본어 TTS 사용은 유지합니다. 안내 화면에서는 광고 배치와 홈 전용 광고 동의 시작을 미룹니다.

## 검증

`npm test`에 안내 상태/동작/자산 16개 검사를 추가합니다. 기존 0.4.0 자동발음까지의 단위 테스트도 모두 실행합니다. 실제 Chromium 전용 `tests/tutorial041-browser.py`는 첫 실행, 단계 이동, 재실행, 완료/건너뛰기, 설정 재생, 키보드/뒤로 가기, 저장 실패, 과거 수업 보존, 실제 서비스워커 오프라인 재로딩을 검사합니다.

나머지 8개 Chromium 회귀 스위트는 최초 안내를 실제 UI로 건너뛴 뒤 기존 학습/통계/폴더/음성/필기 검사를 그대로 실행합니다. 앱에 테스트용 통과 플래그나 CSP 완화를 추가하지 않습니다.

Android 빌드, JVM 정책 테스트, lint 및 API35 계측을 실행하며 기존 회전·재생 서비스 검사와 새 TutorialLifecycleTest를 포함합니다. APK 자산과 검증한 웹 소스의 바이트 동일성 및 서명도 검사합니다. 최종 성공 여부·검사 수는 해당 Actions 실행과 검증 artifact가 기준입니다.

로컬 브라우저 다운로드는 DNS EAI_AGAIN으로 실패하여 CI Playwright를 사용합니다. Browser 플러그인은 이 세션에 제공되지 않았습니다.

## 남은 경계

물리 기기 음질/일본어 발음, 장시간 배터리 절전 상태의 백그라운드 재생, 실제 결제·환불·광고 동의, TalkBack 전수 검수는 별도입니다. 기존 예문 번역 초안과 독립 원어민 전수 검수 상태는 이번 변경에서 완료로 바꾸지 않습니다.

설치 전에 설정 → 기록 백업을 사용하십시오. 내부 debug 서명이 기존 설치와 다를 수 있습니다. 백업 없이 기존 앱을 삭제하지 마십시오.
