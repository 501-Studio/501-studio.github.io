# 코토바 0.4.1 내부 테스트

기능 튜토리얼을 처음 홈을 열 때 5단계로 안내합니다. 완료·건너뛰기는 저장하고 다시 자동으로 띄우지 않습니다. 중간에 앱을 닫으면 마지막 안내 단계부터 이어집니다. 기존 진행 중인 수업으로 바로 복원된 경우에는 수업을 가리지 않고 홈에 돌아왔을 때 안내합니다.

설정 → 사용 방법 → 기능 튜토리얼 다시 보기에서 언제든 처음부터 열 수 있습니다. 닫으면 설정으로 돌아갑니다. 안내 예시의 아는/모르는 단어 선택은 실학습 상태, XP, 복습일, 수업, 단어장 쓰기 기록에 반영하지 않습니다. 새로 저장하는 것은 tutorial의 version/status/step뿐이며 기존 스키마 버전과 DB 이름은 유지합니다.

안내: 급수와 회독 → 발음·쓰기·예문 → 복습·중단/재개 → 단어장·맞춤 학습 → 강도·통계·백업. 진행 버튼, 이전, 단계 선택, 건너뛰기, 키보드 Tab/화살표/Escape와 Android 뒤로가기를 지원합니다. 작은 가로 화면은 내용만 스크롤하고 다음/닫기를 남깁니다.

수업 자동 발음은 안내·일반 모달·백그라운드 뒤에서 시작하지 않도록 추가 가드했습니다. 취소된 음성 완료 콜백이 응답시간 시계를 다시 켜지 않도록 했습니다.

## 검증

`npm test`, `node scripts/verify-bundled-assets.mjs`, `python tests/tutorial041-browser.py`와 기존 036~040 및 자동발음 브라우저 회귀 스크립트를 실행합니다. Android assembleDebug/bundleDebug/testDebugUnitTest/lintDebug 및 실제 API35 에뮬레이터 회전/기록 복원/재생 서비스/튜토리얼 재생성·뒤로가기 계측을 포함합니다. 실행 결과는 Actions artifact를 기준으로 확인해야 합니다.

Browser 플러그인은 이 세션에 없었습니다. 로컬 Chromium의 localhost 이동은 ERR_BLOCKED_BY_ADMINISTRATOR로 차단되어 우회하지 않고 GitHub Actions의 Playwright Chromium에서 검증합니다. 음성 테스트는 호출·취소·완료 확인이며 물리 기기 스피커 청취 검증이 아닙니다. 기존 예문의 전체 언어 검수, 실제 결제/광고/스토어 배포 검증은 이번 자동화 검사의 범위가 아닙니다. 공개 배포 gate를 유지합니다.

## 설치와 소스

versionCode 14 / versionName 0.4.1. 내부 debug 서명이 이전 APK와 다를 수 있으므로 설치 전 설정 → 기록 백업을 먼저 사용하십시오. 백업 없이 기존 앱을 지우지 마십시오. 공개 main/Pages/Play에 배포하지 않습니다.

소스는 `release/tutorial041.py`로 단 한 번 통합한 뒤 검증된 일반 파일로 보존합니다. 이후 일반 `npm test`, `npm run android:sync`, Gradle 빌드가 가능하며 통합 스크립트는 재실행해도 같은 결과입니다. 앱은 내장 Ogg 음원이나 튜토리얼용 네트워크 의존성을 추가하지 않습니다.
