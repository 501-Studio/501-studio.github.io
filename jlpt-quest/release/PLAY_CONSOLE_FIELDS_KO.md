## 실제 학습 및 음성

8,451개 급수별 어휘 항목, 가나 입문, 뜻·듣기·쓰기 학습, 예문, 중단·이어서 학습, 복습, 단어장 폴더·선택 테스트·통계·백업 기능을 제공한다. 8,451개 뜻과 창작 예문·추가 용례·연습 문제의 assistant 전수 검수를 완료하고 근거를 기록했다. 외부 원어민·언어 전문가의 독립 승인으로 표현하지 않는다. 자동 번역 예문에 대한 앱 내 초안 표시는 유지하며 오류 신고를 받는다.

어휘·뜻·예문·획 데이터는 앱에 포함한다. **음원은 내장하지 않고 설치된 일본어 오프라인 TTS만 사용한다.** 음성이 없으면 설치 안내를 표시하며 내장 음원으로 대체하지 않는다. 설치에는 인터넷이 필요할 수 있고 실제 기기 발음·음질을 검증해야 한다.

기본 판매 설정은 꺼져 있고 구매 버튼은 **구매 준비 중 / 비활성화** 상태다. 표시된 fallback 가격은 예정가다. Google Play의 실제 상품 응답과 구매 화면을 최종 가격 기준으로 사용한다. 상품 조회와 기존 구매 조회는 판매 비활성 상태에도 수행될 수 있다.

판매를 켜려면 상품과 요금제, HTTPS 검증 서버, 공개 entitlement key, 서명 앱, 결제 프로필을 확인하고 라이선스 테스터로 구매·대기·복원·취소·갱신·유예·보류·환불을 검증한다. Google 로그인·Play Integrity·계정 귀속·영구 토큰 저장·인증 RTDN·환불 대사 코드는 구현하고 로컬 테스트했지만 실제 배포와 Google 통합 검증은 남아 있다. 구매·복원 계정 연결은 만 14세 이상 확인 후에만 열며 미선택·14세 미만은 차단한다. 판매 기능의 승인 값을 임의로 true로 변경하지 않는다.

## 광고·동의와 청소년 대상

실제 의존성은 Google Mobile Ads 25.4.0, UMP 4.0.0, Billing 9.1.0이며 INTERNET 권한이 있다. AdMob 앱·실제 배너·전면 광고 ID는 생성하고 `admob-production.json`에 기록했다. 계정·앱 심사는 대기 중이며 내부 테스트 빌드는 Google 테스트 ID만 사용한다. 개인정보 메시지, app-ads.txt 등 실제 설정과 게재를 확인한다.

배너는 홈/단어장/내 기록의 별도 네이티브 영역에 배치한다. 전면 광고는 사용자가 완료 화면에서 이동할 때 최소 2챕터 및 180초 간격 조건을 충족하면 표시한다. 학습·필기·구매·구매 확인 중과 오프라인에는 광고를 생략한다.

연령 미선택·14세 미만은 UMP/GMA 초기화와 광고 요청을 차단한다. 14~15세는 CHILD/UMP under-age,16세 이상은 TEEN을 사용하고 G/npa/게시자 개인화 비활성화를 적용한다. 설정에서 변경하면 이전 광고·비동기 동의 결과를 폐기한다. 이것만으로 청소년 보호·동의 규정 준수를 완료로 신고하지 않는다. 실제 합성 manifest·SDK 네트워크·콘텐츠 적합성을 확인한다. 대상 연령과 IARC 결과를 혼동하지 않는다. 실제 앱이 아동 대상으로 평가되는 경우 Families 요건도 적용 여부를 재검토한다.

## Data safety 작성 근거

| 데이터 | 처리 방식과 신고 검토 |
|---|---|
| 단어 진도 / 필기 / 별표 / 폴더 / 통계 | 기기 내부. 광고·구매 검증 서버에 학습 내용을 보내지 않음 |
| 일본어 단어 / 예문 | 설치된 로컬 TTS 엔진으로 전달. 음성 엔진의 별도 정책 확인 |
| IP 기반 대략 위치 | Ads SDK 사용 가능; 정밀 위치 권한 없음 |
| 기기/계정 식별자 | Ads SDK의 실제 버전·연령·동의 설정과 합성 manifest 확인 |
| 광고/제품 상호작용, 진단 | Ads SDK 광고·분석·부정행위 방지 처리 검토 |
| 구매 토큰 / 상품 / 설치 식별자 / 이용권 상태 | 판매 활성화 후 검증 서비스·Google Play 처리. 목적·보관·서비스 제공자 예외 대조 |
| 카드번호 / 결제 비밀번호 | 앱·검증 서버가 받지 않으며 Google Play에서 처리 |
| 백업 JSON | 사용자 선택 파일 위치. 자체 서버 업로드 없음 |

**미수집 앱으로 신고하지 않는다.** 비개인화 광고도 SDK 데이터 처리의 부재를 뜻하지 않는다. API gateway 로그/IP, RTDN 저장, 보관·삭제·해외 처리 및 수탁자 정보를 운영 구성에 맞춰 확정한다. 최신 Google SDK 데이터 안내가 다루는 버전과 프로젝트 버전 차이도 검토한다.

## 계정 신고와 실제 출시 순서

구매 확인용 Google SSO와 기기 간 구매 소유권 결합을 제공하므로 데이터 보안 양식의 계정 생성·삭제 질문은 **계정 있음**으로 보수적으로 신고한다. 앱 설정에 `data-deletion.html` 요청 경로를 추가했다. 같은 페이지를 공개 HTTPS URL로 제공하고 본인 확인, 삭제 범위·법정 보관, 백업 재복구 후 삭제 적용 및 실제 처리 절차를 검증한 뒤 `accountDeletion`을 승인한다. 이메일 요청 경로는 Google 정책이 허용하나, 페이지 작성만으로 삭제 운영 검증이 끝난 것은 아니다. [Google Play 계정 삭제 요구사항](https://support.google.com/googleplay/android-developer/answer/13327111).

1. 백하성 / Studio 501 / 지원 이메일이 실제 개발자 계정·정책과 맞는지 확인한다. 계정 인증, 결제·세금 정보, 법적 약관 등 계정 소유자가 확인할 항목을 정확히 기록한다.
2. 공개 정책 URL·시행일, 한국 배포, 13세 이상 대상 연령, 광고·앱 액세스, Data safety, IARC를 실제 앱에 맞춰 작성한다. 등급 설문은 content-rating-review.json의 실제 사전 항목을 검토한다.
3. 광고·상품·서버 설정과 실제 결제·환불·광고 동의·광고 제거를 검증한다.
4. 실기기 필기/TTS/복원/TalkBack 및 콘텐츠 검수, 업로드 키·release AAB 서명·Play App Signing을 완료한다. 업로드용 개인 키는 Git 밖의 이 PC에서 생성하고 Windows 사용자 권한·DPAPI로 보호했다. Google Play 등록과 별도 기기의 복구용 백업은 미완료이며 앱 서명 인증서는 아직 없다.
5. 계정 유형·생성일을 확인한다. 해당 신규 개인 계정은 12명·14일 연속 opt-in 비공개 테스트와 생산 트랙 접근 승인이 필요하다.
6. 사전 출시 보고서·16 KB 호환성·최종 등록정보와 신고를 확인한 후 사용자가 요청한 심사 제출·출시를 진행한다. 제출 또는 게시 완료는 콘솔 결과가 확인된 경우에만 보고한다.

현재 release gate와 미완료 계정 항목은 사용자의 출시 요청과 별도로 충족해야 한다. 출시 요청은 미확인 정보·검증 결과를 대신 인증하거나 실제 결제 테스트 비용을 임의로 발생시키는 근거가 아니다.
