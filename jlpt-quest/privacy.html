데이터와 개인정보 안내

v0.3.2 내부 테스트 빌드

출시 전 초안입니다. 운영자 이름·연락처·보관 정책과 Play 데이터 보안 신고를 확정한 정식 개인정보처리방침은 아닙니다.

한 획씩 쓰기 · 완전 내장

획 데이터와 위치·방향·모양 비교 코드는 APK에 포함됩니다. 손글씨 모델 다운로드, 서버 인식, ML Kit는 사용하지 않습니다. Android 앱의 인터넷 권한도 제거했습니다. 첫 실행부터 인터넷 없이 필기 학습을 할 수 있습니다. 자유 필기 OCR이 아니라 정해진 글자의 획순을 연습하는 판정 방식입니다.

기기에 저장하는 정보

단어별 학습 결과, 복습 예정일, 수업 진도, 설정, 별표, 현재 글자의 통과한 필기 획을 기기의 저장소에 보관합니다. 별도의 계정·클라우드 서버·광고·분석 SDK는 없습니다. 앱 삭제나 데이터 삭제 전에 백업하세요. 예전 자유 필기의 미완료 그림은 새 획순 판정으로 옮겨 자동 통과시키지 않습니다.

일본어 발음

발음은 기기 TTS 엔진에 요청합니다. 설치된 음성과 엔진에 따라 별도 인터넷 서비스가 사용될 수 있습니다. 이는 해당 음성 제공자의 정책을 따릅니다. 필기 기능은 TTS 설치 또는 네트워크와 무관합니다. 마이크·카메라 권한은 요청하지 않습니다.

백업과 삭제

요청할 때만 JSON 백업을 사용자가 선택한 위치로 내보냅니다. 백업에는 필기와 학습 기록이 포함됩니다. 가져오기는 확인 후 현재 기록을 대체합니다. 설정의 초기화 기능은 학습 기록을 삭제하며, 내장된 공개 콘텐츠는 유지됩니다.

공개 콘텐츠

어휘는 OpenJLPT·EDRDG 등의 공개 자료와 자체 편집 단어입니다. 획 자료는 KanjiVG의 파생 자료입니다. 출처와 변경 사항, KanjiVG 원문 라이선스를 포함합니다. 공식 JLPT 전체 출제 목록이 아니며, 대부분의 전체팩 뜻은 영어로 추가 한국어 검수가 필요합니다.

정식 출시 전

운영자 정보·문의처·공개 정책 URL·대상 연령·스토어 신고·전체 콘텐츠 검수·접근성과 실제 기기 테스트를 완료해야 합니다.
