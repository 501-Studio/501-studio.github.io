# 코토바 0.4.0 내부 테스트판

0.3.9 PR #6을 기반으로 합니다. main, 공개 웹사이트 및 Google Play에 배포하지 않습니다. 광고·구매 기능은 변경하지 않습니다.

## 학습 강도와 여러 글자 쓰기

설정의 학습 강도는 새 회차부터 적용합니다. 진행 중인 회차는 시작 당시 강도를 유지합니다. 모르는 단어 하나당 횟수는 다음과 같습니다.

| 강도 | 뜻 시험 | 듣기 연습 | 듣기 시험 | 쓰기 연습 | 쓰기 시험 |
|---|---:|---:|---:|---:|---:|
| 매우 쉬움 | 1 | 0 | 0 | 0 | 0 |
| 쉬움 | 1 | 1 | 1 | 1 | 1 |
| 중간 | 1 | 1 | 2 | 3 | 2 |
| 어려움 | 2 | 2 | 3 | 5 | 3 |

모든 강도에 새 단어 확인 1회가 있습니다. 틀리거나 힌트를 본 시험 문항은 추가 재시도가 나올 수 있습니다. '한자만 쓰기 연습'이 켜져 있으면 가나만 있는 단어의 연습은 생략되지만 선택한 강도의 쓰기 시험은 유지됩니다.

여러 글자는 원래 단어 위치에서 `□□ → 学□ → 学校` 순으로 표시합니다. 완료한 글자는 탭에도 실제 글자로 남습니다. 혼합 표기는 가나 어미 위치를 유지합니다. 아직 쓰지 않은 뒤 글자로 건너뛰지 않습니다. 힌트를 켠 따라 쓰기는 원래 전체 표기를 보여 줍니다.

## 맞춤 학습

홈/복습/기록의 맞춤 학습에서 약점, 내 단어장, 미니시험, 연속 듣기, 획 연습, 예문 검토를 엽니다.

약점은 뜻·듣기·쓰기, 3회 이상 오답, 최근에는 맞지만 과거 오답이 많은 유형으로 나눕니다. 표시 점은 복습 단계이지 기억 확률이 아닙니다. 0.4 이전에는 독립 풀이 여부가 저장되지 않았으므로 기존 누적 오답을 기준으로 삼습니다.

개인 폴더는 최대 100개, 선택 테스트는 최대 100단어입니다. 폴더 이름 변경·삭제·단어 추가/제거가 가능하며 폴더 삭제는 실제 단어와 학습 기록을 삭제하지 않습니다. 같은 단어가 여러 폴더에 있을 수 있습니다. 선택한 단어의 뜻/듣기/쓰기/전체 테스트를 제공합니다. 기존 수업들은 별도로 보관하며 보관 한도를 넘으면 새 학습을 시작하지 않습니다.

미니시험은 급수마다 20문제, 10분, 읽기·뜻·문맥·유사 표현·용법 5유형입니다. 총 100문항의 자체 작성 시작용 문제은행입니다. 공식 JLPT의 전체 형식·난이도·배점·환산점수를 재현한 시험은 아닙니다. 화면을 나가도 제한시간이 지나며 제출 전에는 정답을 표시하지 않습니다. 시간 만료 시 자동 제출하고 오답을 원래 문제 유형 그대로 다시 풀 수 있습니다.

## 복습과 기록

개인별 복습 간격은 자동 채점의 최근 독립 오답, 연속 정답, 충분한 표본이 있을 때의 상대적인 응답 시간을 사용하는 제한된 규칙입니다. 검증된 망각 확률 모델이나 FSRS라고 주장하지 않습니다. 일찍 맞히거나 같은 수업에서 다시 맞히면 복습일을 뒤로 미루지 않습니다. 틀리면 10분 복습으로 돌아갑니다.

5/10/20분 복습은 화면을 켜고 문제를 보는 시간을 집계합니다. 시간이 끝나도 현재 답과 남은 문제는 저장하고, 종료 또는 5분 추가를 선택합니다. 실제 학습 시간이므로 모의시험의 실시간 제한과 다릅니다.

일정 분산은 미래 복습만 최대 2일, 남은 간격의 20% 안에서 앞당깁니다. 검토 후 적용하며 마지막 분산을 취소할 수 있습니다. 이미 채점되어 달라진 일정은 취소 작업으로 덮어쓰지 않습니다. 모든 날을 원하는 상한 아래로 만들 수 있다고 보장하지 않습니다.

월간 캘린더, 새 단어, 장기 복습 진입, 재오답, 가장 많이 틀린 단어, 첫 풀이 정답률, 급수별 장기 복습 현황을 추가합니다. 과거에 기록되지 않은 정답률을 추정하지 않습니다. 상세 응답 이력은 최근 30,000건을 저장하며 집계 범위를 표시합니다. 기존 7/30/90일 통계와 7일 복습 예정은 유지합니다.

획별 통계는 0.4 이후 실제 획 판정에서 기록하며, 오답 획만 별도로 연습할 수 있습니다. 단어장 반복 쓰기와 획 연습은 시험 통과·XP·장기 복습 단계로 바꾸지 않습니다.

## 예문 품질: 완료 범위와 미완료 범위

전체 8,451개 어휘의 기존 예문 연결을 유지하고 구조·누락·길이·초안·일부 옛 표현 표시를 점검합니다. 자체 작성한 쉬운/자연스러운 문장 200개와 명시적인 다의어 예문 6개를 추가했습니다. 모든 단어에 2개씩 새 문장을 완성한 것은 아닙니다. 모든 다의어의 모든 뜻을 분리한 것도 아닙니다.

`聞く`, `見る`, `頼む`처럼 이번에 명시적으로 작성한 뜻은 각각 구분합니다. 정확한 표제어나 단일 어휘에 연결된 활용형을 강조하고, 원문을 HTML로 해석하지 않습니다. 문장 길이만으로 JLPT 문법 등급이나 자연스러움을 확정하지 않습니다. 기존 번역 초안은 기본적으로 접고 오역 주의를 유지합니다.

**원어민의 전체 의미·문법·난이도 검수는 끝나지 않았습니다.** 구조 점검 통과를 언어적 정확성 보증으로 사용하지 마십시오. 실제 대화에 부적절한 문장 제거와 전 단어의 두 단계 용례 작성은 추가 편집이 필요합니다.

## 연속 듣기와 Android

선택/별표/약점 단어에서 일본어 단어 → 한국어 뜻 → 일본어 예문 순으로 재생합니다. 한국어 뜻과 예문, 목록 반복을 각각 선택합니다. 기기의 오프라인 음성만 사용하며 내장 녹음 파일이나 외부 번역 요청은 없습니다. 일본어/한국어 음성 미설치 시 안내합니다.

Android는 사용자가 시작한 미디어 foreground service로 화면이 꺼져도 재생하도록 구현합니다. 미디어 알림에서 이전·재생/일시정지·다음·정지를 제공합니다. 오디오 포커스 상실 및 이어폰 분리 시 일시정지합니다. 마이크·정밀 위치·부팅 자동 시작 권한은 추가하지 않습니다. 브라우저는 백그라운드로 이동하면 일시정지하고 이 제한을 표시합니다.

자동화 TTS adapter는 요청 순서·오류·완료를 확인하는 용도이며 실제 휴대전화 음질·읽기 정확성·화면 끈 상태의 장시간 청취 검증을 대신하지 않습니다.

## 빌드와 데이터 보호

소스 전송용 최초 통합은 기본 파일과 결과의 SHA256을 모두 검사합니다. 실제 소스를 보존한 후에는 source-applied 표시로 재구성을 반복하지 않고 일반 소스를 빌드합니다. `node scripts/build-study040.mjs`, `npm test`, `npm run android:sync`, Gradle을 사용합니다.

QA 최종 결과는 PR와 Actions 결과에서 확인하십시오. 사용자 데이터를 테스트 예시로 채우지 않습니다. 내부 APK는 debug 서명이므로 이전 빌드와 충돌할 수 있습니다. 설치 전 기존 앱 설정에서 기록을 백업하고, 백업 없이 앱을 삭제하지 마십시오. 공개 배포 승인 gate는 유지됩니다.
