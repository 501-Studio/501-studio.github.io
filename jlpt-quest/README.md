# 코토바 v0.3.4 · 완전 오프라인 회독

현재는 Google Play 정식 제출 전 내부 테스트 빌드입니다.

## 핵심 흐름

한 챕터는 최대 30단어입니다.

1. 30단어를 빠르게 한 장씩 확인
2. 아는 단어 / 모르는 단어 분류
3. 필요할 때 히라가나·한국어 뜻 표시
4. 모르는 단어만 발음 듣기·한자 쓰기 학습
5. 모르는 단어만 뜻·듣기·쓰기 시험
6. 오답 유형만 다시 확인
7. 모두 통과하면 해당 챕터 회독 수 증가

홈과 챕터 목록에는 N5 · 第1章 · 1회독 · No.1~30 형식으로 진행 상태를 표시합니다.

## 완전 오프라인

Google Play용 Android 빌드에는 다음을 모두 포함합니다.

- N5~N1 전체 어휘 데이터
- 한자/가나 획 데이터 2,244문자 / 22,615획
- 일본어 발음 Ogg Opus 파일 전체
- 개인정보처리방침, 이용약관, 오픈소스/저작권 고지

Android manifest에는 INTERNET 권한이 없습니다. 별도 손글씨 모델 다운로드나 기기 TTS가 필요하지 않습니다.

발음은 빌드 시 Open JTalk + HTS Voice NIT ATR503 M001을 이용해 생성하여 앱에 포함합니다. 동일 읽기는 하나의 음성 파일을 공유합니다.

## 듣기 UX

듣기 학습/문제 화면에 진입하면 해당 단어를 자동으로 1회 재생합니다. 자동 재생이 끝나면 문제 선택이 활성화됩니다. 더 듣고 싶을 때는 듣기 버튼 또는 0.7× 버튼으로 다시 재생할 수 있습니다.

## 쓰기

획의 절대 시작 위치는 강제하지 않습니다. 입력을 중심/크기 정규화한 뒤 방향·길이·꺾임·전체 형태를 비교합니다. 기본 통과선은 약 60% 유사도이며, 통과한 획은 기준 위치로 스냅됩니다.

역방향, 너무 짧은 입력, 여러 획을 한 번에 그린 낙서, 굽은 획의 직선 대체는 별도 안전장치로 거부합니다.
