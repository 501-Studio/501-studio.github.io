# 코토바 v0.3.3 · 30단어 회독 챕터

현재는 Google Play 출시 전 내부 테스트 버전입니다.

## 학습 흐름

한 챕터는 최대 **30단어**입니다.

1. 30단어를 빠르게 한 장씩 봅니다.
2. 각 단어에서 **아는 단어 / 모르는 단어**를 선택합니다.
3. 필요할 때만 **히라가나 표시하기 / 한국어 뜻 표시하기**를 눌러 확인할 수 있습니다.
4. 아는 단어는 이번 회독의 집중 시험에서 제외합니다.
5. 모르는 단어만 발음을 듣고 한자를 직접 씁니다.
6. 모르는 단어만 뜻·듣기·쓰기 시험을 봅니다.
7. 남은 오답 유형이 없을 때만 해당 챕터의 회독 수가 1 증가합니다.

홈과 커리큘럼에는 **N5 第1章 / 1회독 / No.1~30** 같은 형태로 현재 챕터와 회독 횟수를 표시합니다. 같은 챕터를 다시 열면 다음 회독이 시작됩니다.

## 직접 쓰기

손글씨는 APK에 내장된 획 데이터와 로컬 판정 코드만 사용합니다. 별도 모델 다운로드나 인터넷 권한이 필요하지 않습니다.

v0.3.3에서는 시작 위치를 정확히 맞추도록 강요하지 않습니다. 한 획을 그린 뒤 손을 떼면 절대 위치를 제거하고 **방향·길이·꺾임·전체 모양**을 비교합니다. 모양 유사도가 대략 **60% 이상**이고 역방향이나 과도한 낙서가 아니면 통과시키고 약 170ms 동안 기준 획 위치로 보정합니다.

따라서 시작 위치가 조금 달라도 비슷한 모양이면 통과하지만, 역방향·너무 짧은 획·한 번에 여러 획을 그린 낙서·굽은 획을 완전히 직선으로 대체한 입력은 계속 거부합니다. 이 기능은 자유 필기 OCR이 아니라 **정해진 글자의 획 학습을 위한 자동 보정**입니다.

기존 N5~N1 전체 어휘에 쓰이는 2,244문자 / 22,615획이 APK에 포함됩니다.

## 객관식

뜻/듣기 객관식은 모바일에서도 **4개 보기를 2×2 그리드**로 한 화면에 표시하도록 구성합니다. 선택 후 하단의 정답 확인 버튼으로 제출합니다.

## 커리큘럼 데이터

전체팩은 현재 다음 급수별 어휘 항목을 포함합니다.

- N5 669
- N4 655
- N3 1,798
- N2 1,844
- N1 3,485
- 합계 8,451 급수별 항목

공개 원본 8,334항목에 중복 병합과 자체 한국어 시작 어휘 보완을 반영했습니다. 공식 JLPT 전수 출제 목록이 아니며, 급수 간 같은 단어가 존재할 수 있습니다. 한국어 뜻 397항목 외에는 영어 원문 뜻이 남아 있어 정식 출시 전 교육 검수가 필요합니다.

## 빌드 및 검증

```sh
cd jlpt-quest
npm run build
npm test
npm run android:sync
cd ../kotoba-android
gradle :app:assembleDebug :app:lintDebug
```

GitHub Actions는 전체 단어/획 팩 생성, Node 회귀 테스트, Android debug APK 빌드/lint, 실제 Chromium Canvas·IndexedDB·터치 상호작용 검사를 수행합니다.

검증 항목에는 다음이 포함됩니다.

- 30단어 챕터 구성과 회독 횟수
- 아는/모르는 분류와 모르는 단어만 시험
- 히라가나/뜻 개별 표시
- 객관식 4개 보기가 모바일 한 화면에 표시되는지
- 시작 위치를 이동한 획이 모양 60% 이상일 때 통과하는지
- 역방향·낙서·너무 짧은 획은 거부하는지
- 진행 중 필기와 회독 상태의 IndexedDB 복원
- 네트워크가 없는 새 브라우저 컨텍스트에서 번들 자산만으로 시작과 필기 판정이 되는지

브라우저 자동 검사는 물리 Android 기기에서 다양한 사람의 실제 필체를 측정한 것이 아닙니다. 정식 출시 전 실제 기기와 사용자 필체 테스트가 필요합니다.
