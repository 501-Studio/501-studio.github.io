# 코토바 퀘스트 · JLPT 회독

모바일 우선의 게임형 일본어 단어 학습 **v0.1.0 프로토타입**. 듀오링고처럼 친근한 단계형 경로와 보상을 사용하되, 자체 브랜드와 새싹 캐릭터 '모찌'를 사용합니다.

## 지금 사용할 수 있는 기능

- N4 기본 시작 / N5 전환. 각 레벨 24단어, 3챕터: 총 48개 자체 편집 샘플.
- 챕터마다 카드 회독 → 뜻 퀴즈 → 직접 쓰기 → 듣기 → 종합 챌린지.
- 뜻·쓰기·듣기 **별도 복습 일정**. 카드 회독과 손글씨는 별도의 자가평가 기록.
- 일본어 직접 입력 자동 채점: 한자/가나 허용, 전각·반각 정규화, 가타카나→히라가나 비교. 로마자는 정답으로 취급하지 않음.
- 글자 도움 기능. 힌트를 쓰면 정답이어도 숙련 승급 대신 재학습 처리.
- 단어 듣기, 0.7배 천천히 듣기, 소리만 듣고 뜻 고르기. 기기에 설치된 일본어 TTS 사용.
- 손가락·펜·마우스 손글씨, 되돌리기, 지우기, 따라 쓰기. **필기 인식/자동 채점은 아님**.
- XP, 레벨, 일별 목표, 연속 학습, 챕터 회독 횟수, 성취 배지. 하트로 학습을 차단하지 않음.
- 단어장 검색, 별표 단어, 예문, 단어별 다음 복습일, 후리가나 on/off.
- 답안·세션·진도 localStorage 저장, 이어 학습, JSON 백업/가져오기, 삭제 확인.
- 반응형 UI, PWA manifest, 해당 앱 경로로 한정한 service worker.

## 실행과 테스트

외부 패키지 설치나 API 키가 필요하지 않습니다. Python 3와 Node.js 22 이상을 사용합니다.

```bash
cd jlpt-quest
npm start
# http://localhost:4173 에 접속
npm test
```

ES modules를 사용하므로 index.html을 file://로 직접 열지 말고 HTTP 서버로 실행하세요. GitHub Pages 등 정적 호스팅에서는 폴더 전체를 같은 경로에 올리면 됩니다. 원래 저장소 루트와 다른 앱은 변경하지 않습니다.

## 복습 규칙

복습 간격은 **10분 → 1일 → 3일 → 7일 → 14일 → 30일**입니다. 이것은 초안의 설명 가능한 규칙 기반 스케줄러이며 FSRS 구현이나 학습 효과가 검증된 개인화 모델로 주장하지 않습니다.

첫 정답은 10분 뒤로 예약합니다. 예정 시간이 지난 문제에 다른 세션에서 정답을 맞히면 다음 단계로 올라갑니다. 틀림/힌트 사용은 첫 단계와 10분 후 일정으로 돌아갑니다. 같은 세션에서는 세 문제를 사이에 두고 재출제하며, 남은 문제가 적으면 끝에 넣습니다. 유형당 추가 재시도는 두 번으로 제한하여 무한 반복을 막습니다. 같은 세션에서 고친 정답이나 예정일 전 자율 연습으로 다음 복습일을 뒤로 미루지 않습니다. 오답 표시는 이후 예정된 복습에서 두 번 연속 정답을 맞힐 때 해제됩니다.

'완전히 익힌 단어' 수는 **뜻·쓰기·듣기 모두 7일 단계 이상**일 때만 증가합니다. 카드·필기 자가평가로 이 수치를 올리지 않습니다. 같은 날짜의 같은 단어·유형에는 XP를 중복 지급하지 않습니다. 챌린지는 첫 시도 정답률 70% 이상, 건너뛴 문제 없음일 때 완료됩니다. 다섯 학습 단계를 모두 마쳐야 회독 횟수가 증가합니다.

## 듣기와 데이터 한계

일본어 TTS 음성 목록을 확인하고, 재생 시작 이벤트 후에만 듣기 답안 제출을 허용합니다. 일본어 음성이 없거나 재생이 실패하면 메시지를 보여주고, 성공으로 기록하지 않습니다. 건너뛰기는 XP·기억 단계·듣기 성공으로 처리하지 않습니다. 기기·브라우저·설치 음성에 따라 음질, 일본어 음성 지원 및 오프라인 음성 지원이 달라집니다. 원어민 녹음, 발음 평가, 음성 인식은 없습니다.

기록은 기기·브라우저별이며 로그인/서버 동기화는 없습니다. 브라우저 저장 공간 삭제, 시크릿 모드 종료, 기기 변경 전에 백업하세요. 백업 가져오기는 확인 후 기존 기록을 대체합니다. 불완전하거나 지원하지 않는 백업은 거부하며, 손상된 기존 저장 데이터는 자동 덮어쓰지 않습니다.

현재 어휘는 **체험용 자체 편집 샘플**입니다. 공식 기출, 유료 교재, 듀오링고 콘텐츠를 복사하지 않았습니다. N5/N4 분류는 편집상 근사치이고 N3/N2/N1 및 문법·독해·시험형 청해는 아직 없습니다.

## 파일 구조

- `src/content.js`: 샘플 단어·예문·챕터·학습 유형
- `src/engine.js`: 복습 간격, 세션, 채점, 보상, 기록 검증
- `src/app.js`: 화면 구성, 해시 라우팅, UI 이벤트, 저장과 백업
- `src/audio.js`: 일본어 TTS 선택/오류 처리
- `src/handwriting.js`: 포인터 기반 필기 캔버스
- `src/ui.js`: 공통 아이콘, 버튼, 자체 캐릭터
- `styles.css`: 모바일·데스크톱 디자인
- `tests/engine.test.mjs`: 순수 로직 회귀 테스트
- `PLAN.md`: 완료/미완료/다음 작업

## 검증 범위

Node 테스트 16개 통과. Chromium 렌더링 하네스에서 10개 UI 검사를 통과했습니다: 320/390/768/1440px 가로 넘침, 일본어 입력, 힌트 처리, 오답 재출제, 듣기 성공/실패 흐름, 필기, 단어장, 설정, 백업 내보내기 등. 런타임 JavaScript 오류는 없었습니다.

이 실행 환경의 관리형 Chromium은 네트워크 탐색을 차단하여, 브라우저 검사는 로컬 소스를 메모리에 렌더링하는 방식으로 진행했습니다. 해당 하네스의 저장소와 성공 음성은 모의 객체입니다. 상태 직렬화/재복원은 별도 확인했으나 **실제 iPhone/Android 음성 출력, 일본어 IME 조합, 실제 오리진의 localStorage·다중 탭·service worker·설치·오프라인 동작은 실기기 검증 전**입니다. 앱 소스에는 모의 객체가 포함되어 있지 않습니다.
