# 코토바 v0.3 · 한자 회독 수업

출시 준비 중인 내부 테스트용 앱입니다. Google Play 정식 출시 완료 버전이 아닙니다.

## 구현된 학습

N5~N1의 고정 커리큘럼. 회차당 5단어를 뜻 확인 → 발음 듣기 → 직접 한자 따라 쓰기로 배운 뒤, 그 회차의 모든 단어에 대해 뜻·듣기·손글씨 시험을 봅니다. 한 유형이라도 남으면 완료되지 않으며 보충 시험으로 연결됩니다. 사용자가 정답이라고 직접 결정하는 버튼은 없습니다.

한자 손글씨는 한 글자씩 손가락/스타일러스로 씁니다. 食べる는 한자 食을 쓰며, 学校는 学·校를 각각 씁니다. 한자가 없는 어휘만 가나를 씁니다. 히라가나 표시 설정, 글자별 필기 저장, 되돌리기/지우기/필기 재생, 급수별 홈 현황, 단어 검색/별표, 복습 예정/오답 모음, 백업/가져오기를 구현했습니다.

Android: Google ML Kit 일본어 인식의 첫 후보를 정답 한자와 비교합니다. 정답을 인식기에 보내 후보를 유도하지 않습니다. 최초 모델 다운로드가 필요하며 실기기 정확도는 별도 검증해야 합니다.
웹: 글꼴 기준 형태 비교 방식의 제한적인 자동 판정입니다. 일반 OCR 또는 Android 인식과 동일하지 않습니다. 판독 불가/모델 없음은 정답으로 처리하지 않습니다.

## 실행

Node.js 22+, Python 3이 필요합니다. 앱 자체에 외부 npm 런타임 패키지나 API 키는 없습니다.

```sh
cd jlpt-quest
npm run build   # 고정 공개 원본 다운로드, 실제 전체팩 검증, 자체 아이콘 생성
npm test
npm start       # localhost:4173
```

배포용 ZIP에는 전체 데이터와 아이콘이 이미 포함됩니다. GitHub 소스 체크아웃에서는 build를 먼저 실행하세요. 파일을 file://로 직접 여는 대신 HTTP 서버를 사용하세요.

Android 소스는 저장소의 ../kotoba-android에 있으며, 다운로드 ZIP에서는 ../android에 있습니다.

```sh
KOTOBA_ANDROID_DIR=../kotoba-android npm run android:sync
cd ../kotoba-android
# Java17, AndroidSDK36, Gradle8.13 환경
 gradle :app:assembleDebug :app:lintDebug
```

GitHub Actions는 전체팩 생성 → 40개 Node 테스트 → 웹 자산 포함 → Android 디버그 빌드·lint를 실행합니다. 내부 테스트 APK는 빌드 성공 시 해당 Actions artifact에 첨부됩니다. main과 기존 공개 사이트는 아직 변경하지 않았습니다.

## 세 차례 검증

1. 수업/복습 로직 재구성: 24개 테스트, 모든 단어의 필수 유형 통과 조건, 자가평가 제거, 저장 검증.
2. 화면/상호작용 31개 검사: 전체 수업, 중복 정답 방지, 음성 완료 후 이동, 히라가나/필기 복원.
3. 전체팩 로직 포함 40개 테스트, 28개 화면 검사: 8,451항목 커리큘럼, 320/390/768/1440px, 저장 실패, 늦은 인식 응답 무시, 웹 형태 판정 굵기 영향 보정. 별도로 합성 획 28사례의 형태 판정을 검사했습니다.

브라우저 URL 접속이 관리 정책으로 차단된 실행 환경이므로 Playwright는 메모리 렌더링 하네스를 사용했습니다. 실제 Canvas는 검사했으나 저장소, 음성과 native 인식 응답 일부는 명시적 모의 객체였습니다. **실제 Android 인식 정확도, 휴대폰 음성, Android 파일 선택·오프라인 복원, 모든 글자의 자연 필체는 아직 검증하지 않았습니다.** 통과 개수를 실기기 인식률로 해석하면 안 됩니다.

## 출시 차단 조건

`npm run release:check`와 Gradle release task는 전체팩/한국어 현지화와 실기기·콘텐츠·개인정보·서명·테스트 승인 없이 실패하도록 구성했습니다. 승인 예시를 임의로 true로 바꾸지 마세요. 개인정보 페이지는 운영자 정보 확정 전 초안입니다. 공개 서버 동기화, 정식 서명 AAB, Play Console 등록/심사는 아직 완료되지 않았습니다.
