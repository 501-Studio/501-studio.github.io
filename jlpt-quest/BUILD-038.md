# 코토바 0.3.8 내부 개발본

PR #4의 `feat/kotoba-037-learning`에서 분기한 `feat/kotoba-038-study-flow`입니다. main, GitHub Pages 및 Google Play 공개 버전을 배포하지 않습니다.

## 학습 흐름

- 정답 제출 뒤 선택지/필기판 대신 정답과 예문 카드 한 장을 표시합니다. 예문 듣기, 0.7배 듣기, 정지, 다음 문제 버튼을 함께 제공합니다. 여러 예문은 한 장씩 넘깁니다.
- 미채점 시험에는 예문으로 정답을 노출하지 않습니다. 히라가나 설정은 예문 읽기 표시에도 적용됩니다.
- 모든 단어 쓰기 및 가나 쓰기 단계에 힌트와 정답 보기가 있습니다. 도움받은 쓰기는 독립 회상 정답으로 기록하지 않습니다.
- 획 인식의 허용 점수를 0.52에서 0.45로 완화했습니다. 이는 내부 가중 점수이며, 정확도나 사람의 필기 유사도 백분율을 뜻하지 않습니다. 방향·길이·낙서 거부 조건은 유지합니다. 한번 틀린 획을 고쳐 쓰면 최종 성공을 막지 않습니다.

## 중단, 재개, 복습

현재 수업과 보관한 수업을 각각 `session`, `suspendedSession`으로 저장합니다. 본수업 한 개와 단어 복습 한 개를 오갈 수 있습니다. 문제 위치, 선택지 선택, 필기, 도움 사용 여부를 함께 보존합니다.

수업 상단 닫기 → 저장하고 나가기 → 홈의 이어서 하기 순서로 재개합니다. 같은 메뉴에서 저장하고 단어 복습하기를 선택해도 본수업은 보관됩니다. 복습이 없을 때 기존 수업을 지우지 않습니다.

이번 회차 처음부터는 확인 후 수업 위치만 되돌립니다. 기억 스케줄, XP, 완료한 회독 기록, 보관한 다른 수업은 삭제하지 않습니다. 같은 회차 ID를 유지하여 이미 보상받은 기억 항목을 다시 처리하는 부작용을 방지합니다. 이전 백업도 읽을 수 있습니다.

## 예문 데이터

기존 예문은 유지하고 `data/examples-expanded.json`을 추가로 읽습니다. 새 데이터는 어휘 ID에 명시적으로 연결합니다. 단순 부분문자열 포함 여부로 관련 없는 단어에 예문을 붙이지 않습니다.

확장 데이터 빌드는 총 8,451개 어휘 ID에 일본어와 한국어 문장이 모두 있는지 검사합니다. 실제 결과는 `data/example-coverage.json`과 검증 artifact를 확인해야 합니다. 이 검사는 언어적 정확성의 전체 검수와 다릅니다.

일본어 용례는 출처 ID가 있는 Tatoeba/EDRDG 자료와 새로 작성한 예문을 사용합니다. 한국어 자동번역 초안은 화면에 표시하고 출처 링크를 제공합니다. 새로 생성한 읽기도 자동 생성 표시를 붙입니다. 추가 문장·읽기는 독립적인 원어민 전체 검수를 마치지 않았으며 원자료의 드문 표기·읽기나 다의어에 주의가 필요합니다.

예문 듣기는 기기에 설치된 일본어 오프라인 TTS를 사용합니다. 없으면 설치 안내가 표시되며 단어 음원을 예문 음원인 것처럼 대신 재생하지 않습니다. 단어의 기존 내장 음원은 그대로 유지합니다. 번역 모델은 앱에 포함하지 않으며 학습 기록을 외부 번역 서비스로 보내지 않습니다.

## 검증 및 재현

`npm test`는 학습·저장·필기·음성 경계의 회귀 테스트입니다. 전체 예문을 조립한 후 `node --test tests/examples038.test.mjs`를 추가 실행합니다. 실제 브라우저 검증 스크립트는 `tests/release038-browser.py`와 `tests/examples038-browser.py`입니다. 기존 036/037 브라우저 테스트도 실행합니다.

Browser 플러그인이 세션에 없고 로컬 브라우저 접속이 제한되어 GitHub Actions의 실제 Playwright Chromium으로 검사했습니다. 단위 테스트만으로 화면 정상 작동을 주장하지 않습니다. 음성 경계 테스트의 mock은 실제 스피커 청취 테스트가 아닙니다.

최종 workflow는 전체 예문 검증, 브라우저 회귀, APK/AAB 빌드, Android 단위 테스트·lint, 에뮬레이터 회전/Activity 재생성 테스트, APK 내부 자산과 검증 소스의 바이트 동일성 검사를 수행합니다. 성공 여부는 Actions 결과를 확인하십시오. 물리 기기별 음질·손글씨 체감은 별도 검증 대상입니다.

화면 폭 360/390/412px의 일반 세로 화면에서는 정답·예문·다음 버튼을 한 화면에 배치합니다. 짧은 가로 화면, 글자 확대, 긴 예문은 내용을 잘라 숨기지 않고 필요한 스크롤을 허용합니다.

## 설치와 기록 보호

APK는 내부 테스트용 debug 서명입니다. CI 빌드 간 서명이 다를 수 있으므로 기존 앱의 설정 → 기록 백업을 먼저 사용하십시오. 설치가 충돌하더라도 백업 없이 기존 앱을 삭제하지 마십시오. 새 설치 후에는 백업 가져오기로 기록을 복원할 수 있습니다.

이 작업은 공개 배포 승인이나 전체 원어민 검수, 실제 기기 음성 검증을 대신하지 않습니다. 기존 production release gate는 유지합니다.
