## 검증에서 수정한 핵심 문제
1차: 일부 단계를 모두 틀려도 완료하던 조건 제거. 자가평가를 숙련도에 합산하지 않음. 새 단어→듣기→필기→전체 시험을 하나의 세션으로 구성.
2차: 음성 시작이 아닌 종료 후 통과, 늦은 비동기 응답 무시, 정사각 필기장, native 메시지 payload 일치, 다른 포인터 간섭 방지.
3차: 전체팩과 시작 수업 ID 유지, 오프라인 재실행의 단어팩 축소 방지, 글꼴 획 굵기에 대한 웹 형태 비교 보정, 작은 화면 현황 숫자와 필기 통과 체크 위치 수정.

Android 빌드: 폐기된 SDK tools 설치 요청을 platform-tools로 변경했고, ML Kit 19.0.0의 실제 recognition 패키지 경로에 맞춰 import를 수정했습니다. 최종 빌드 결과는 Actions에서 확인하며, 컴파일 통과가 실기기 품질을 보증하지는 않습니다.
