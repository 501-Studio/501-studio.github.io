# v0.3.2 개발 기록

## 이번 요구사항
APK에 손글씨 판정이 내장되어 첫 실행부터 동작하고, 한 획을 그을 때마다 허용 오차 안이면 정해진 위치로 보정되어야 한다.

## 구현
- [x] 외부 ML Kit 및 모델 자동 다운로드 코드 제거
- [x] APK에 KanjiVG 파생 2,244문자 / 22,615획 패키징
- [x] 위치·방향·끝점·순서·길이·경로를 비교하는 로컬 판정
- [x] 통과 획 보정 애니메이션, 잘못된 획만 지우고 재시도
- [x] 다음 획 시작점과 방향 안내 / 시험에서 안내 숨김
- [x] 부분 획의 저장·복원과 한 획 취소 / 기존 그림은 자동 통과시키지 않음
- [x] 가이드, 시험, 재출제 흐름 연결 및 점수 부풀림 방지
- [x] Android 인터넷 권한 제거, 고정 버튼의 시스템 바 가림 수정
- [x] 신규 회귀 검사와 실제 Chromium/Canvas/IndexedDB 오프라인 자산 검사 코드
