# 개발 계획과 진행 기록

업데이트: 2026-09-23 · 버전: v0.1.0

## 제품 방향

짧은 회독을 반복할 수 있는 모바일 우선 JLPT 앱. '듀오링고 느낌', 철저한 복습, 단어 쓰기, 단어 듣기를 핵심 요구로 둡니다. 게임은 학습 동기를 돕되, 틀렸다는 이유로 학습을 잠그거나 실제보다 높은 숙련도를 표시하지 않습니다. 자체 이름은 코토바 퀘스트, 캐릭터는 새싹 모찌로 임시 결정했습니다.

## 구현 선택과 제한

기존 저장소가 정적 사이트이므로 별도 빌드 도구/서버 없이 ES modules + CSS를 사용했습니다. 모든 새 파일은 `jlpt-quest/` 아래에만 둡니다. 외부 유료 API, 로그인, 추적 SDK, 비밀 키를 추가하지 않았습니다. 학습 데이터는 기본적으로 브라우저에 저장됩니다. TTS 제공 방식은 기기 음성 엔진에 따릅니다.

이미지 생성 도구를 사용할 수 없어 생성형 시안 대신 코드 네이티브 UI와 자체 SVG 캐릭터로 초안을 만들었습니다. 생성형 이미지 또는 사용자가 승인한 별도 시안과 일치한다고 주장하지 않습니다. 실제 브라우저 렌더에서 색상, 경로 간격, 타이포그래피, 아이콘, 버튼/정답 상태, 모바일 배치를 확인했고 잠긴 단계의 글자 대비를 개선했습니다.

Browser 플러그인이 없어 Playwright를 사용했습니다. 관리형 Chromium의 URL 탐색 제한 때문에 메모리 렌더링으로 검사했으며, 실제 네트워크 탐색이나 실기기 음성 재생을 검증한 것으로 간주하지 않습니다. 원어민 녹음/손글씨 인식/자동 필기 채점/계정 동기화/완전한 JLPT 커리큘럼은 미구현입니다.
