대화 내용이 저장되거나 AI에게 전달되나요?

아니요. 현재 버전은 외부 AI API나 분석 서버를 사용하지 않습니다. 대화 입력과 계산은 브라우저 메모리에서만 이루어지며, 대화를 쿠키·로컬 저장소·데이터베이스에 저장하지 않습니다. “원문 지우고 새로 하기”를 누르면 입력과 분석 상태를 지웁니다. 사이트 접속 자체에 필요한 IP·접속 기록은 호스팅 업체가 처리할 수 있지만, 대화 입력을 전송하는 기능은 없습니다.

어떤 형식의 대화를 분석할 수 있나요?

나: 오늘 뭐 했어?처럼 이름과 내용이 있는 텍스트, [이름] [오후 3:20] 내용 형식, 2026. 9. 18. 오후 3:20, 이름 : 내용 형식 등을 지원합니다. .txt 파일은 UTF-8과 CP949/EUC-KR을 읽습니다. 내보내기 형식은 기기와 버전에 따라 다르므로 감지된 이름과 메시지 수를 확인해 주세요. 대화는 최대 50만 자·2만 메시지이며, 두 사람이 각각 2개 이상, 합계 6개 이상의 메시지를 보내야 합니다. 형식이 인식되지 않으면 “이름: 내용”으로 정리해 주세요.

상대방 관심도나 연애 가능성을 정말 알 수 있나요?

알 수 없습니다. “관심 신호”는 질문·긍정 표현·메시지 참여 비율을 조합한 임의의 놀이 지수이며 실제 호감, 성격, 심리 상태나 관계의 미래를 측정하지 않습니다. 높은 점수도 사랑의 증거가 아니고, 낮은 점수도 무관심의 증거가 아닙니다. 중요한 관계 판단에는 사용하지 마세요.

점수는 어떻게 계산하나요?

텐션은 메시지 수의 균형(최대 30점), 웃음 메시지 비율(최대 25점), 질문 메시지 비율(최대 15점), 발신자 전환 비율(최대 15점)에 기본 15점을 더한 놀이 점수입니다. 질문 메시지는 ? 또는 ？가 들어 있는 메시지입니다. 적극성은 상대방의 질문 비율·참여 비율·일부 긍정 표현을, 관심 신호는 적극성 60%와 메시지 균형 40%를 조합합니다. 답장 리듬은 유효한 답장 간격의 중앙값을 0~100으로 환산한 지표입니다. 같은 입력과 같은 참여자 선택에는 같은 결과가 나옵니다. 점수에 과학적 타당성이나 심리 측정 근거는 없습니다.

시간이 없거나 단체 대화라면 어떻게 되나요?

시간이 없는 텍스트도 메시지 비율과 대화 유형은 분석됩니다. 답장 간격을 계산할 수 없으면 “시간 정보 부족”으로 표시합니다. 날짜 없는 시각은 같은 날의 입력 순서로만 계산하고 역순 시간은 제외합니다. 6시간을 넘는 공백도 제외합니다. 단체 대화는 선택한 두 사람의 메시지만 비교하되, 다른 참여자가 끼어든 구간을 두 사람 사이의 직접 답장으로 간주하지 않습니다.

카톡·인스타그램에 바로 공유할 수 있나요?

“결과 이미지 저장”으로 PNG를 저장해 원하는 앱에 올릴 수 있습니다. “이미지 공유하기”는 기기에서 지원하는 공유 메뉴를 열며, 카카오톡·인스타그램 등의 노출 여부는 기기와 앱에 따라 다릅니다. 전용 카카오 SDK 공유는 현재 연결하지 않았습니다. 링크 공유에는 점수·유형만 들어가고 이름·대화는 제외됩니다. 공유 링크는 서버에서 검증하지 않아 주소를 수정하면 점수도 바뀔 수 있습니다.

정말 무료인가요? 광고가 안 나오는데요.

현재는 기본 분석과 추가 분석 모두 무료입니다. 광고 계정이나 승인된 광고 단위가 연결되지 않아 실제 광고를 요청하지 않습니다. 광고를 본 척하는 카운트다운도 없습니다. 향후 광고가 도입될 경우 별도 고지하며, 보상형 광고는 사용자가 동의하고 광고 제공업체가 보상을 확인한 경우에만 추가 분석을 열도록 연결해야 합니다.
