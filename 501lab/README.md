# 501 Lab website

Public website for https://501lab.com/.

Cloudflare Workers Builds deploys the main branch with root directory /501lab and deploy command npx wrangler deploy. The build command is exit 0 because these are static files.

Only public/ is uploaded. Keep research notes, unpublished product information, and design sources outside this directory. The material images are labeled as concept images on the website.

To update the website, edit public/ and commit changes to main. Preserve the existing 501lab.com custom domain and Cloudflare Email Routing records.

Current design: approved image-led v5, 21 October 2026. Typography uses Pretendard under the license in public/assets/OFL.txt.
