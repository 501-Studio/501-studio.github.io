Current focus

Project DURA is an early-stage biomedical R&D program for a next-generation dural substitute concept. The program has progressed through problem definition, specialist feedback, and design architecture, with engineering validation planned next.

Project MIND is a digital mental wellbeing product under development, focused on low-friction mood check-ins, routine continuity, and safety-aware support pathways.

501 Lab also maintains public software work through the 501-Studio GitHub account.

Development model

Research, document, test, iterate.

We treat scientific R&D and software development as different disciplines, while using the same principle: define the problem clearly, expose assumptions, and gather evidence before making stronger claims.
